# 工作空间统一导航

- 范围：导航仅出现在登录后私有页面（首页、文件、上传、我的分享、我的账号及私有详情页）；公开分享、登录、注册使用独立外壳，不显示私有菜单。PWA 更新提示则可出现在 `/app/` 的所有路由。
- 页面归属：`router.tsx` 的 `handle.navigation` 决定当前主菜单；首页→`home`，文件目录及素材预览→`files`，上传→`upload`，分享列表/新建/编辑→`shares`，账号→`account`。

## 页面区域

| region | 内容 |
|---|---|
| `nav.desktop` | 固定顺序：首页、全部文件、上传素材、我的分享、我的；下方分隔为准备中且禁用的足迹地图、旅行、回收站。所在项用 `aria-current="page"` 标识。 |
| 各页面的 `*.mobileNav` | 同一顺序的五个可用入口：首页、文件、上传、分享、我的；准备中功能不占移动底栏位置。 |
| `shell.update` | 全站右下角 | `/app/` 应用有可用新版本时出现的更新提示；包括稍后和用户主动立即更新。公开路由也可能看到。 |

## 可执行动作

| data-agent-id / 工具名 | 类型 | 作用 | 参数 | 危险 |
|---|---|---|---|---|
| `nav.home`、`nav.files`、`nav.upload`、`nav.shares`、`nav.account` | 链接 | 前往对应工作区一级页面；文件入口返回根目录 | 无 | 否 |
| `nav.mobile.home`、`.files`、`.upload`、`.shares`、`.account` | 链接 | 移动端同序入口，当前态由路由归属确定 | 无 | 否 |
| `nav.map`、`nav.trips`、`nav.trash` | 禁用按钮 | 未接入的一级功能不可进入 | 无 | 否 |
| `nav.home.brand` | 链接 | 桌面品牌入口返回首页 | 无 | 否 |
| `shell.update.later` | 按钮 | 隐藏新版本提示；下次回到标签页可再次看到 | 无 | 否 |
| `shell.update.apply` | 按钮 | 用户确认后激活新版本并刷新页面；上传或编辑中应先完成当前操作 | 无 | 否 |
| `tool: checkForAppUpdate/activateAppUpdate` | 工具 | 检查新的 Service Worker，或在用户确认后激活并刷新 | 注册对象 / 更新函数 | 否 |
| `tool: currentPagePath/navigationSource/returnTarget/returnLabel` | 工具 | 记录站内来源和上一级来源、校验返回路径并生成明确标签；直开详情页使用稳定兜底 | 路径、查询参数 | 否 |

## 页面可读状态

| 状态 | 含义 | 来源 |
|---|---|---|
| `handle.navigation` | 当前页归属菜单，与 URL 前缀解耦；预览归文件，分享配置归分享 | 路由表 |
| `location.state.from/previousFrom` | 从列表等页面进入详情时的站内来源及其上一级来源，包含查询参数；不存签名 URL | 页面内导航 |

## 跳转

- 素材详情从首页最近素材、文件目录或上传完成项进入；优先返回进入前首页/文件搜索结果/目录；直接打开或无有效来源时回文件的真实父目录，读取失败可回文件根目录。上传完成项进入预览时回已保存文件的目录，不假装上传队列会跨页保存。
- 创建分享从文件行菜单进入时取消/返回原目录或搜索结果；直接打开时回分享列表。编辑分享始终回分享列表。保存后统一回分享列表。
- 账号页从菜单或顶栏进入时可返回原工作区页面；从分享创建详情进入并回去时仍保留原文件来源。直接打开账号页则回首页。上传页返回进入前页面，没有有效来源则回路由参数所指目录或文件根目录，**不会**随上传目标选择变化。
- 未登录访问私有路由时保留路径和查询串，登录后只回校验过的站内页面；公开分享是独立访客页面，不显示工作区菜单。私有数据及其权限仍由 API 验证。

## 特殊说明

- 文件页根目录菜单保持站内拖放目标，目录快速访问是文件页专属内容；上传中的离页警告和队列卸载行为维持原样。
- 各导航项为语义化链接/禁用按钮，配置来自 `services/navigation.ts`，菜单可用性和显示顺序由 `WorkspaceNavigation` 统一；不同页面仅保留专属信息块与布局 CSS。所有返回目标必须用 `returnTarget` 校验，不接受站外跳转或媒体签名地址。
- PWA 仅对 `/app/` 启用（其他部署需显式配置）；每 30 分钟及重新进入标签页检查新版本。更新需用户主动点击，Service Worker 只预缓存静态外壳，不缓存 Cookie API、COS 私有媒体和上传凭证；PWA 外壳可加载不代表离线时私有数据可用。
