# 前端页面目录（草案，供设计使用）

> 仅列页面与入口，不含视觉与交互细节。优先级与 `需求与技术方案.md` 一致。
> 登录态说明：公开 = 无需登录；登录 = 需登录。
> 首页已按 PC/H5 静态设计稿接入 React 根路由；首页汇总接口在本地实现，未发布到生产。上传页 `/upload` 和文件页 `/files/:folderId?` 已接入 React；独立 `design/files.html` 仍只使用虚构样例，不访问云端。

## 页面之间的主要跳转

```
登录/注册 → 首页 → 文件
文件 ──预览──→ 地图（定位到该素材）
地图 ──点位/地区──→ 地区详情 ──→ 文件预览
文件 / 旅行 ──分享──→ 分享访问页
```

## 设计时请重点考虑

1. 文件页是日常高频页面：大量缩略图的浏览性能与批量操作。
2. 地图页是核心差异点：点亮效果、县界层与点位层的层级、省/市/县统计的展示方式。
3. 上传是长时间任务：必须能在切换页面时继续，并能看到进度。
4. 视频素材很大：预览用转码后的 HLS，原片下载单独入口。
5. 首页、登录与账号设置第一阶段同时设计 PC 和 H5；文件/上传/预览/地图页面也需提供各自的桌面端与移动端交互，不强制两端共用同一套布局。
