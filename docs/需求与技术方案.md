# movehome 需求与技术方案（草案 v0.1）

> 面向旅游博主的个人网盘 + 足迹地图。素材存 COS，按"去过的县"点亮地图。

## 1. 已确定的技术选型

| 层 | 选型 |
|---|---|
| 前端 | React + Tailwind + Arco Design，部署到腾讯 Makers，域名 `convenience.top` |
| 后端 | Node.js 20（Lighthouse 上海，`api.convenience.top`），建议 Fastify 或 NestJS |
| 数据库 | 服务器现有 MongoDB 8.0（新建独立库 + 独立用户，开启认证） |
| 存储 | 腾讯云 COS，桶 `test-cos-1312827847`，地域 `ap-chengdu`，私有读写，根前缀 `movehome/` |
| 视频/图片处理 | COS 数据万象（CI）：转码、截帧、缩略图 |
| 地图 | 腾讯地图 JavaScript API GL，县级 GeoJSON 多边形点亮 |
| 第一版范围 | 仅网页；仅国内；不做多租户计费，但账号系统完整 |

## 2. 总体架构

```
浏览器 (convenience.top, Makers)
  │  ① 登录/元数据/业务       ② 直传、直读（临时凭证 / 签名 URL）
  ▼                           ▼
api.convenience.top (nginx → Node)      腾讯云 COS (ap-chengdu) + 数据万象
  │                                      ▲
  ▼                                      │ ③ 提交转码/截帧任务
MongoDB（本机）──────────────────────────┘
```

设计原则：
- **文件字节不经过后端**。上传、下载、播放全部浏览器直连 COS，后端只签发凭证和记录元数据。服务器只有 2 核 / 1.9 GB，必须这样。
- **重活交给 COS 数据万象**，后端不跑 ffmpeg。
- **GPS 解析放在浏览器**（上传前读取），减轻服务器压力。

## 3. 功能清单与优先级

### P0（MVP）
1. **账号**：注册、登录、退出、修改密码、找回密码（邮件）。
2. **文件管理**：文件夹树、上传（分片、断点续传、队列）、重命名、移动、删除到回收站、搜索。
3. **预览**：图片、视频（HLS 预览流）、音频。
4. **位置解析**：图片 EXIF GPS；视频同名 `.SRT` 的逐帧坐标；解析不到的支持手动指定。
5. **地图**：素材点位聚类、点击看缩略图。
6. **县级点亮**：按素材位置判定所属县，点亮并统计（县/市/省）。

### P1
7. **旅行（Trip）**：按时间与位置自动归并素材，可手动调整，带封面和标题。
8. **轨迹**：导入 GPX/KML，从 SRT 提取飞行轨迹，地图上画线并统计里程。
9. **分享**：链接 + 提取码 + 有效期，可分享文件、文件夹、旅行。
10. **足迹海报**：生成点亮地图图片。
11. **手动打卡**：不依赖素材的地点记录。

### P2
12. 时间轴回放（足迹按时间逐步点亮）。
13. 素材状态标记（待剪辑/已剪辑/已发布）、评分、标签。
14. AI 标签与语义搜索。
15. 格子迷雾（战争迷雾）点亮模式。
16. 桌面端或 SD 卡自动同步。

### 暂不做
多博主运营后台、收费与配额扣费（仅预留字段）。

## 4. 关键方案

### 4.1 上传
- 后端签发约 30 分钟的 STS 临时凭证，权限限定到服务端生成的单个对象 Key，仅允许简单/分块上传相关操作；浏览器不能选择 bucket、用户目录或对象 Key。
- 浏览器通过 COS JS SDK 直传 COS，支持分块上传；文件名、大小、MIME 和目标文件夹先向 `POST /uploads/credentials` 申请上传会话。
- `POST /uploads/complete` 只接收 `uploadId`；后端按会话中绑定的用户、对象 Key 和期望大小执行 HeadObject，验证对象存在且大小一致后才幂等创建文件节点，不信任客户端传来的 Key 或完成时自报大小。
- 单文件大小受 COS 单对象上限约束（当前 API 上限 5 TB）；配额尚未启用。上传哈希/秒传暂不实现，待哈希算法、去重范围及校验规则明确后再单独定义。
- COS 桶需配置 CORS：允许实际前端来源（当前 Lighthouse `/app/` 为 `https://api.convenience.top`，本地开发为 `http://127.0.0.1:5173`），开放分块上传所需的方法和头（含 `ETag`）；当前 `https://api.convenience.top` 对 COS 的 PUT 预检返回 403，桶规则补齐前该入口不能浏览器直传。服务端 COS 子账号需具备 HeadObject 读取权限及 STS 临时凭证签发权限。

### 4.2 播放与下载
- 私有桶，访问一律使用**短时效签名 URL**（后端签发，建议 10–60 分钟）。
- 视频上传完成后，后端向数据万象提交转码任务，产出 720p HLS 和封面，原片保留。
- 转码状态：`pending → processing → done / failed`，前端轮询或后端回调更新。

### 4.3 位置解析与县级判定
- **坐标系**：大疆素材为 WGS-84，腾讯地图与主流县界数据为 GCJ-02，入库前统一转换并同时保存两种坐标。
- **县界数据**：使用县级行政区划 GeoJSON（约 2800 个区县）。需注意数据来源的许可与审图号要求，**上线前必须核实**。
- **判定**：县界导入 MongoDB，建 `2dsphere` 索引，用 `$geoIntersects` 判断点所属县，结果写入素材的 `regionCode`。
- **前端渲染**：县界原始精度很大，需要做简化，并按省份懒加载，不能一次下发全国。
- **统计**：点亮的县集合 → 汇总到市、省。
- 边界附近、海岛、境外坐标需要兜底：判定不到县时记为"未归属"，允许用户手动指定。

### 4.4 账号与安全
- 注册登录：邮箱 + 密码；密码用 argon2id 哈希。
- 会话：短期 access token（约 15 分钟）+ 可轮换 refresh token，放 `httpOnly; Secure; SameSite` Cookie。
- 前端 `convenience.top` 与 API `api.convenience.top` 同属一个站点，Cookie 可设置在父域，需明确 CORS 白名单与 CSRF 防护。
- 所有数据带 `userId`，每个接口强制归属校验；分享链接只暴露只读签名 URL。
- 登录接口限流，防暴力破解；预留 `role`、`quota`、`status` 字段。
- 密钥（COS SecretId/Key、腾讯地图后端 Key、JWT 密钥）只放服务器环境变量。
- COS 使用**子账号 + 最小权限**，仅允许操作该桶的 `movehome/*`，禁止使用主账号密钥。

### 4.5 COS 目录约定
```
movehome/
  users/{userId}/
    originals/{yyyy}/{mm}/{fileId}.{ext}   原始文件
    previews/{fileId}/index.m3u8 ...        HLS 预览
    thumbs/{fileId}.jpg                     缩略图/封面
    tracks/{fileId}.json                    解析后的轨迹
  shares/                                    预留
```
文件名使用 `fileId`，不直接用原始文件名，避免特殊字符与冲突；原始名存在数据库里。

## 5. MongoDB 数据模型（初稿）

| 集合 | 关键字段 |
|---|---|
| `users` | email(唯一), passwordHash, nickname, role, status, quotaBytes, usedBytes, createdAt |
| `sessions` | userId, refreshTokenHash, userAgent, expiresAt |
| `nodes`（文件与文件夹） | userId, parentId, type(file/folder), name, path, size, mime, hash, cosKey, status, uploadSessionId, uploadedAt, deletedAt, deletedRootId, createdAt, updatedAt |
| `media_meta` | nodeId, userId, takenAt, device, width, height, duration, location(GeoJSON Point, WGS84), locationGcj, regionCode, locationSource(exif/srt/manual), transcode{status, jobId, previewKey, thumbKey} |
| `tracks` | userId, nodeId, name, line(GeoJSON LineString), distance, startAt, endAt |
| `regions` | code, name, level(province/city/county), parentCode, geometry(GCJ-02, 2dsphere), centroid |
| `region_simplified` | code, level, geometrySimplified（供前端渲染） |
| `lit_regions` | userId, regionCode, firstVisitedAt, mediaCount, trips[] |
| `trips` | userId, title, startAt, endAt, coverNodeId, nodeIds/规则, regionCodes |
| `places` | userId, name, location, regionCode, note, visitedAt（手动打卡） |
| `shares` | userId, targetType, targetId, token, passwordHash, expiresAt, accessCount |
| `upload_sessions` | userId, nodeId, parentId, name, expectedSize, mime, cosKey, status(pending/completed), createdAt, expiresAt, credentialExpiresAt, completedAt |

关键索引：`users.email` 唯一；`nodes(userId,parentId,deletedAt)`；`nodes(userId,type,status,deletedAt,uploadedAt desc,_id desc)`；`upload_sessions(expiresAt)` TTL；`media_meta.location` 2dsphere；`regions.geometry` 2dsphere；`lit_regions(userId,regionCode)` 唯一。

## 6. API 清单（初稿，前缀 `/api/v1`）

- **认证**：`POST /auth/register`、`/auth/login`、`/auth/refresh`、`/auth/logout`、`/auth/forgot`、`/auth/reset`；`GET /me`
- **文件**：`GET /nodes`、`GET /nodes/:id`（祖先目录）、`POST /nodes/folder`、`PATCH /nodes/:id`、`DELETE /nodes/:id`、`POST /nodes/:id/restore`、`GET /nodes/:id/url`（私有文件签名 URL 已上线；缩略图用途本地实现待云端验收）、`GET /nodes/search`
- **上传**：`POST /uploads/credentials`（已实现，STS 会话）、`POST /uploads/check`（秒传，未实现）、`POST /uploads/complete`（已实现，COS 校验与节点入库）
- **首页**：`GET /home/summary?recentLimit=4`（本地已实现，待部署）；按登录用户已入库且未删除文件统计数量、大小与最近素材，足迹/旅行返回 `not_ready`，详情见 `docs/首页接口契约.md`。
- **地图**：`GET /map/points`、`GET /map/regions/lit`、`GET /map/regions/:code/geometry`、`GET /map/stats`
- **旅行**：`GET/POST/PATCH/DELETE /trips`
- **轨迹**：`GET/POST /tracks`
- **分享**：`POST /shares`、`GET /s/:token`（公开）
- **处理回调**：`POST /internal/ci-callback`（需校验来源）

### 上传 API 契约

- 两个接口均要求登录；上传用户只取自认证会话，节点父级必须是该用户的活动文件夹。
- `POST /uploads/credentials` 请求体为 `{ name, size, mime?, parentId? }`，名称最长 255 字符，大小为 0–5 TB（5,000,000,000,000 字节），`parentId` 缺省或 `null` 表示根目录。服务器生成 `uploadId`、`fileId` 和 COS Key；客户端不得提交 bucket 或 Key。
- 成功返回 `{ uploadId, fileId, bucket, region, key, credentials, expiresAt }`。返回的 STS 凭证有效约 30 分钟，只能对这一个对象执行上传/分块上传相关操作；响应设为 `Cache-Control: private, no-store`。长期 COS 密钥不返回给客户端。
- `POST /uploads/complete` 请求体仅 `{ uploadId }`。后端按会话记录执行 HeadObject，要求对象存在且实际 `Content-Length` 与申请时的 `size` 相同，父目录仍有效后才创建 `type=file` 节点；完成调用可安全重试，已完成会话返回同一节点，不重复入库。
- 上传会话最长保留 24 小时，`upload_sessions.expiresAt` 由 TTL 索引清理；该 TTL 只清理 Mongo 会话，不会清理 COS 对象或未完成分块。上线前仍需配置 COS 未完成分块回收，并规划过期上传对象的孤儿清理。STS 到期早于会话到期。父目录在上传期间被删除时，完成登记返回冲突，不会写入节点。
- 节点的 `uploadedAt` 记录入库时间，与 `updatedAt` 分离，避免后续改名/移动影响“最近添加”排序。客户端 MIME 仅作为声明元数据；对象大小由 COS 校验。哈希校验、秒传和配额扣减尚未实现。

### 节点 API 契约

- 所有节点路由要求登录，数据查询和变更始终限定为当前用户；跨用户或不存在的节点统一返回 `404`。
- `GET /nodes` 默认列出根目录（`parentId` 缺省），可传 `parentId` 列出活动文件夹的直接子项；`view=trash` 列出回收站顶层项目，带 `parentId` 时列出该回收站文件夹的直接子项。支持 `offset`（默认 `0`）、`limit`（默认 `50`，最大 `100`）、`sortBy=name|createdAt|updatedAt|size`、`sortOrder=asc|desc`，响应为 `{ items, total, offset, limit }`。
- `POST /nodes/folder` 请求体为 `{ name, parentId? }`；`parentId` 缺省或 `null` 表示根目录。文件夹名称去除首尾空格，长度 1–255，不能包含斜杠、反斜杠或 NUL。
- `PATCH /nodes/:id` 只接受 `name`、`parentId`；缺省字段不变，`parentId: null` 表示移动到根目录。移动目标必须是当前用户的活动文件夹，禁止将文件夹移动到自身或其后代；目前不强制同目录名称唯一。
- `DELETE /nodes/:id` 为软删除；删除文件夹时递归将其子树移入回收站。子节点记录 `deletedRootId` 以关联本次删除根节点。响应包含 `{ deletedCount }`。
- `POST /nodes/:id/restore` 恢复回收站顶层项目；恢复文件夹会一并恢复该次递归删除的整棵子树。子节点须先恢复其所在的回收站根文件夹。响应包含 `{ node, restoredCount }`。本次暂不提供永久删除或清空回收站接口。
- `GET /nodes/:id/url?purpose=preview|download` 要求登录，仅为当前用户未删除、已入库且处于 ready 状态的文件签发 GET 链接；缺省为 preview，不可预览的 MIME 则作为附件下载。返回 `{ url, expiresAt, name, mime, previewable }`，10 分钟有效，响应 `Cache-Control: private, no-store`。通过 `COS_READ_DOMAIN=assets.convenience.top` 配置已绑定此桶的自定义源站域名，签名时将该域名作为 Host；不配置则沿用 COS 默认域名。上传仍使用 COS 原域名。签名链接本身可授权访问，切勿记录、公开或共享缓存；桶始终保持私有读写。
- `GET /nodes/search?q=...` 对当前用户未删除节点的名称做不区分大小写的字面子串匹配（不把搜索词解释为正则表达式），支持 `offset`、`limit`，响应为 `{ items, total, offset, limit }`。
- 节点响应字段为 `id,parentId,type,name,size,mime,status,createdAt,updatedAt,uploadedAt,deletedAt`；不会向客户端暴露内部 `cosKey`。
- `GET /nodes/:id` 验证归属与活动状态，响应 `{node, ancestors}`，其中 `ancestors` 从根级到父目录排列，供深链接恢复路径；无权或已删除返回 404。
- 对象 Key 仅从数据库读取且须位于当前用户的 `originals/` 前缀；HTML、SVG、SRT 等不在内联白名单时强制下载。已签链接到期前仍有效，软删除不能立即撤销；默认 COS 域名对新建桶可能不支持浏览器直接预览。原片签名接口已上线，但仍需登录用户用已上传素材验证真实预览。`purpose=thumbnail` 固定处理为最长边 320px JPEG（源图片不超过 30 MiB），处理参数随 URL 一同签名且默认关闭；上线前需小样本验证私有桶 CI 处理、实际缩图字节、签名 Host 与计费，再设置 `COS_IMAGE_PROCESSING_ENABLED=true`，失败时不回退大原片。

## 9. 风险与待办

| 风险/事项 | 说明与建议 |
|---|---|
| 服务器内存小 | 2 核 1.9 GB，已有 Mongo 与 Node；大任务全外包给 COS；上线后监控内存，必要时加 swap 或升级配置 |
| 桶在成都、服务器在上海 | 后端只签凭证，影响很小；用户浏览器直连 COS，跨地域无额外压力；若以后后端要拉取文件做处理会有延迟与流量 |
| 桶名带 `test` | 作为正式存储需确认是否要新建专用桶；若沿用，务必做好前缀隔离与子账号限权 |
| 县界数据合规 | 数据来源、许可、审图号上线前核实；图层使用腾讯官方底图 |
| 县界体积 | 需做几何简化与按省懒加载 |
| 私有桶成本 | 流量和请求费用需关注；缩略图与预览走签名 URL，可适当缓存 |
| MongoDB 安全 | 确认现有实例是否已启用认证；新建独立用户；做每日备份 |
| 邮件找回密码 | 需要邮件发送服务（如腾讯云 SES），第一版可先不做，仅保留修改密码 |
| 替换 aishangli | 停服务前先备份其 nginx 配置和 Mongo 数据 |
